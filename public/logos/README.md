# Logos de instituciones

Coloca aquí los logos oficiales. En cuanto exista el archivo, el sitio lo muestra
automáticamente (sobre fondo blanco) y deja de usar el monograma de color.

## Formato recomendado
- **SVG** (ideal) o PNG/WebP con fondo transparente.
- Preferiblemente la versión horizontal o el isotipo cuadrado (se recorta a un cuadro).
- Nombre del archivo = `key` de la institución (ver lista abajo), en minúsculas.

| Davivienda             | `davivienda.svg`           |
| Banco Promerica        | `promerica.svg`            |
| Coopeservidores        | `coopeservidores.svg`      |

| Grupo Mutual           | `grupo-mutual.svg`         |
| Mutual Alajuela        | `mutual-alajuela.svg`      |
| INS                    | `ins.svg`                  |

(También sirve `.png` o `.webp`, por ejemplo `bac.png`.)

## Dónde conseguirlos
- Sitio oficial de cada institución (pie de página / sala de prensa / manual de marca).
- El `key` está definido en `src/lib/institutions.ts`.

> ⚠️ Los logos son marcas registradas de cada entidad. Confirma el permiso de uso
> antes de publicar en producción.
